WHAT YOU CAN TEST WITHOUT YOUR HOME COMPUTER
=============================================
Everything below works on a phone with Termux + Chrome. Nothing needs a second person. (Seeing a real
stream needs a computer that hosts it: the pretend opponent below can be matched, but sends no picture.)

PART 0 - Unpack (once)
  In Termux:   pkg install python unzip
               termux-setup-storage          (tap Allow)
               cd ~ && unzip -o ~/storage/downloads/NetplayMatchmaker.zip
               cd nm

PART 1 - Invite page (1 minute)
  Chrome:  http://127.0.0.1:7778/join?g=gba:test-game&c=ABCD2345
  You should see "You're invited to play Test Game" and an Open button.

PART 2 - The Android app (needs the APK; see PART 4)
  Install the APK. Open it > Settings: Matchmaker address 127.0.0.1, port 7777. Save.
  Tap Add: system PlayStation 2, name  Urban Reign , leave the file path empty.
  Termux is already running  sh phone-test.sh  (leave it open; swipe between apps).
  Tap the game in "Your games" (it starts and you join the queue).
   - Within a second the app should say it found an opponent and open its own stream player. It
     says "Waiting for your friend's computer..." and, after about 20 seconds, that your friend's
     computer didn't answer (the pretend opponent has no picture to send). The on-screen buttons,
     Stats and Leave work; Back twice leaves.
   - Also check: an invite link appeared in the app; "Share invite link" opens the share sheet;
     "Join with a link" accepts the link from PART 1 (and says clearly if it's wrong).
   - Leaving works: tap a game, then tap "Leave queue"; it says "You left the queue".
  Native lane (optional, needs RetroArch + mGBA core + a GBA file): stop Termux, run
     sh phone-test.sh native
  add a GBA game named  Test Game  with its file path, tap Find. The app should open RetroArch
  with the game and tell you to connect to 127.0.0.1 (copied). (There's no real host to join; this
  only checks the launch.)

PART 3 - What can NOT be tested away from home
  A real stream (it needs a computer hosting it), and the real host: screen capture, hardware
  encoding, game sound, the virtual controller.
  When you're home: on the Linux PC run  python3 desktop/stream_host.py --doctor  and send me the output.

PART 4 - Getting the Android app built while you're out
  Fastest route (Termux):
    pkg install git gh
    gh auth login          (choose GitHub.com > HTTPS > login with a web browser or paste a token)
    cd ~/nm
    git init -b main && git add -A && git commit -m "netplay matchmaker"
    gh repo create Retro-Netplay --private --source=. --push      (or: git remote add origin ... && git push)
  Then in the GitHub app: your repo > Actions > "Build Android APK" > Run workflow. It takes a
  few minutes. Open the finished run > Artifacts > NetplayMatchmaker-APK, download, unzip, install
  app-debug.apk. If the build fails, open the run, copy the red error lines, and send them to me.

SEND ME (any of these helps)
  - Screenshots of the app's main window and its stream player.
  - What happened at each "Try" above.
  - Any red error text from Termux or GitHub Actions.
